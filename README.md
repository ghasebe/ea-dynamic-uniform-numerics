# Numerical Verification for Drift Analysis of the $(1+1)\text{-EA}$

[![DOI](https://zenodo.org/badge/1156101871.svg)](https://doi.org/10.5281/zenodo.18620301)

SageMath notebook providing computer-assisted verification of numerical bounds in the drift analysis of the $(1+1)\text{-EA}$ on dynamic linear functions with i.i.d. $\mathrm{Uniform}(0,1)$ weights.

## Contents

- `notebooks/` -- verification notebook.
- `results/` -- exported constants (`results.json`) produced by the notebook.

## Reproducibility

This notebook is intended to be run in a SageMath environment.
